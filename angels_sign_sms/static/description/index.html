Verify signers
with a code by SMS

Before signing, each signer types a one-time code sent to their mobile phone. It adds a second factor to the email link and records the verification in the audit trail.

Odoo 20 · Community & EnterpriseAdd-on for Angels SignUses Odoo SMS credits

How it works

Three steps

1

Choose SMS per signer

In the editor or the request, set the verification to Email link + SMS code. The mobile number comes from the contact and can be edited.

2

The signer gets a code

When the signer opens the email link, Odoo sends a 6-digit code by SMS. It is valid for 10 minutes.

3

Verified and logged

Only after entering the right code can the document be signed. The verification is part of the certificate of completion.

SMS credits. Messages are sent with Odoo's SMS service (IAP), which is billed by Odoo S.A. in credits. Buy credits from Settings before using SMS verification.
